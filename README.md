# Kilim

Kilim markasının herkese açık sayfası: https://eymenrm.github.io/kilim/

- `index.html`: Kilim ve Kilim Fabrika tanıtımı (TR/EN)
- `gizlilik/`: Kilim Fabrika gizlilik politikası (TR/EN), Google OAuth onay ekranında bağlantısı var
- `stil.css`: ortak stil; renkler marka dosyasıyla aynı

Sayfa düz HTML'dir; çerez, analiz aracı ya da dış yazı tipi yoktur. İleride Kilim'in kendi alan adıyla web sitesine dönüşecek.
